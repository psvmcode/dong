## 排查类文档的统一思路

线上问题排查的文档都按同一个顺序组织：

```
现象 → 分清性质 → 定位到具体原因 → 救火（按见效速度排序）→ 根治 → 兜底
```

**救火永远是第一步**。系统正在烧的时候做优化是来不及的，
先让它别烧了，给你争取到排查时间——这与 [`../mq/backlog.md`](../mq/backlog.md)
里处理消息堆积的思路一致：**先止血（扩容/分流），再根治（优化消费逻辑）**。
