# 2026-07-25

## ERP + CRM 综合管理平台项目启动

### 项目规划
- 技术选型：Spring Cloud Alibaba + JDK 21 + Vue 3 + TDesign + Vant 4
- 6个微服务：gateway(8080)、auth(8081)、crm-server(8082)、erp-product(8083)、erp-order(8084)、erp-finance(8085)、system(8086)
- 每个服务独立数据库，物理隔离
- 部署：本地 Docker Compose + 腾讯云 CVM (YOUR_PUBLIC_HOST)
- ORM：原生 MyBatis（非 MyBatis-Plus），分页手写 LIMIT
- SDD 开发模式：先写 OpenAPI 规格 → 确认 → 编码
- 目录结构：backend/、frontend/、docs/、deploy/，每层有 README 索引

### 编码规范 Skill 已创建
- Skill 路径：`.codebuddy/skills/dong-standards/`
- 核心规则：无任何注释、SQL 关键字小写、DDL 先行、方法前后空行（方法体内部不空行）、实体属性前后空行
- 新增规范：@Valid 校验、分页 PageRequest/PageResult、Nacos 配置分层、Feign client 规范、枚举管理、LocalDateTime 统一、resultType 映射、@Transactional 回滚、空集合返回[]、Constants 常量管理
- 每次编码前必须加载此 Skill
