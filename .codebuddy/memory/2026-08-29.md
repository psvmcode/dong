RocketMQ 4.9.7 / Kafka(待装) / Elasticsearch 8.15.3 / MongoDB 7 / MariaDB 10.11

### 架构决策
- 单 Maven 模块，顶层按限界上下文分（cache / classic / seckill / redpacket / social /
  search / tcc / mq / doc / replica），每个上下文内部按传统分层
  （controller / service+impl / mapper / entity / dto / enums）
- 用户明确要求遵循 skill【dong-standards】，核心：禁止任何注释（含 Javadoc）、

- 设计原理全部写进根目录 README.md，不写进代码注释

### 关键实现要点
- framework/ 层：多级缓存（L1 Caffeine + L2 Redis + 失效广播 + 延迟双删）、
  Redisson 分布式锁、四种限流算法、布隆过滤器、MQ 抽象（local/rocketmq/kafka 路由）
- 主库必须显式声明 DataSource + sqlSessionFactory + @Primary，
  否则从库 @MapperScan 会抑制 MyBatis 自动扫描导致主库 Mapper 全部失效

### 重要踩坑（详见 README 第七节）
1. Redisson RScript 用 StringCodec 时 Lua 返回值解析错误，库存已扣却返回 null →
   改用 Spring Data Redis DefaultRedisScript
2. 枚举语义错误：DeductStatus.of(9) 中 9 是剩余库存不是状态码 → 改 fromResult 按符号判断
3. JDK 21 虚拟线程 getId 不唯一，Redisson 可重入锁失效 → 改用平台线程池
4. ES 原生客户端写入不应用 @Field，动态映射成 text 导致聚合失败 →
   启动时用原生客户端显式创建映射
5. ES 日期格式不匹配（ISO vs yyyy-MM-dd HH:mm:ss）导致 bulk 全部失败且被静默忽略 →
   改 strict_date_optional_time，并检查 bulk 响应 errors()
6. Spring Data 反射访问 BigDecimal 被 JDK 21 模块系统拒绝 → 用原生客户端定义映射
7. IK 插件必须写进 Dockerfile，容器内手工安装会在 compose down 后丢失
8. RocketMQ 必须设 brokerIP1 为公网 IP；5.3.1 在此环境启动失败用 4.9.7；
   命名卷权限问题改用 bind mount
9. RocketMQ syncSendOrderly 会丢失 keys → 改用原生 send + MessageQueueSelector
10. springdoc 2.x 与 Spring Framework 6.2 冲突 → 排除 SwaggerConfig，
    OpenAPI 文档仍可从 /v3/api-docs 获取
11. 多数据源下必须显式声明主库 @Primary 的 DataSource 与 sqlSessionFactory
12. MongoDB 密码含 @ 必须 URL 编码为 %40
