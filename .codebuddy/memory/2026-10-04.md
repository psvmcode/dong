## 本次踩到的坑（可复用）

- **环境 NODE_ENV=production 会让 npm 跳过 devDependencies**，`npm install` 后 vite/vue-tsc 全缺，
  必须 `npm install --include=dev`。README 已写明。
- **浏览器无头验证方案**：本机无 playwright，但装了 Google Chrome，用
  `Google\ Chrome --headless=new --virtual-time-budget=8000 --dump-dom <url>` 即可判断 SPA 路由是否真实挂载，
  按页面关键字 grep 即可批量校验。
- 后端 actuator 整体 status 会因为 MariaDB 不可用变成 DOWN，但业务接口仍可用；
  前端因此把「不可达」与「有组件不可用」分开显示，避免误判成后端挂了。
