## 踩过的坑

- **code-explorer 子代理只有只读工具**,给它们"直接改文件"的任务会白跑(其中一个直接 terminated)。但它们给出的逐文件行号清单很有价值;批量落地改用 /tmp 下的 Python 脚本 + 主线程改结构性部分。
- **脚本批量改 CSS 的两个副作用**:① `color: #fff` 若统一映射成 `var(--lab-card)` 会在白底变白字,必须按属性区分(`color:` → 正文色,`background:` → 卡片白);② 清理 emoji 时把 `✓`/`●`/`›`/`↔` 这类**功能符号**也删了,导致签到"已签"标记、TCC 箭头、链路连接符变空白 —— 已改成语义文字/状态点。以后批量删 emoji 要列白名单。
- 深色块改浅底后,`opacity: 0.x` 只会让文字发虚,一并删掉。
