## Agent 模块 P1 落地（commit cda5a42，已 push）

真实模型客户端 + 并行工具调用 + 14 个工具。

**并行实现的唯一正确写法**：先全部 `submitTool` 提交再逐个 `get()`，
串行模式则是边提交边等——两者共用同一套提交逻辑。
绝对不要在任务里再套一层 `supplyAsync`（工具执行本身已经提交到 `agentToolExecutor`），
否则并行时外层任务占着线程等内层任务排队，池一满就自己把自己锁死。
结果必须按**发起顺序**回填（tool_call_id 匹配），不是完成顺序。

**模型客户端三条硬规则**：

- 工具调用是分片到达的（第一块给 id/name，后续块只给 arguments 的一小段），
  必须按 `index` 累积后合并
- 已经推出去的正文**绝不重试**，重试只在「一个字都没推」时进行，否则页面两段接不上
- 不加 `stream_options.include_usage`（部分兼容端点会报错），token 一律用 `TokenEstimator` 粗估

**接现有 service 的两个坑**：

- `SearchServiceImpl` 带 ES 开关，关闭时容器里没有 bean → 用 `ObjectProvider<SearchService>`，
  硬注入会让整个应用起不来（一个可选模块不该决定主应用的生死）
- `POST /api/cache/lab/stats` 走的是 `@Bean` 组件 `com.dong.framework.cache.CacheStats`（不是 service）；
  `POST /api/classic/lab-record/*` 只有 Mapper 没有 service

**副作用工具的超时要单独覆写**：`classic.lock_lab` 加锁实测十几秒，
用默认 15 秒必然超时（现在 90 秒）；`limiter_compare` 40 秒、`penetration_lab` 30 秒。
默认参数也要调小（8 线程 × 5 次），否则整轮运行被拖到超时。

**未验证**：真实模型。环境里没有 `LAB_AGENT_API_KEY`
（`deploy/.env` 里其它中间件密码是真实的，但 agent 的没配）。
要验证需先配 key，再把 `dong.agent.llm.provider` 改成 `openai`。

## 目录迁移：deploy / db / doc → src/main/resources（已提交 dc78227）

用户要求把顶层三个目录整体移动到 `src/main/resources/` 下（移动，非复制；不做 HTTP 访问映射；不打进 jar）。

- 顶层现在只剩 `pom.xml`、`README.md`、`src`
- `pom.xml` 加了 `<resources>` excludes（`deploy/**` `db/**` `doc/**`），编译后 `target/classes` 里确认没有这三个目录
- `application.yml` → `spring.config.import: optional:file:./src/main/resources/deploy/.env[.properties]`
- **`.gitignore` 必须同步路径**（第 58/62 行带路径的规则是 anchored，移动后会失效）：
  `doc/topic/crossborder-interview-prep.md` → `src/main/resources/doc/topic/...`，
  否则私人面试文档会进 public 仓库；`deploy/.env` → `src/main/resources/deploy/.env`
- `gen-initdb.sh` **无需改动**：它按 `dirname $0/..` 推 ROOT，db 与 deploy 仍同级
- `docker-compose.yml` / `setup-env.sh` / `print-env.sh` 都是相对自身目录，无影响；服务器 `/opt/dong-lab` 保持扁平结构不变
- doc 内 `../../db/schema.sql` 这类相对链接仍然有效（doc 与 db/deploy 现在同级于 resources 下），
  只有从项目根描述的裸路径（`db/schema.sql`、`deploy/...`）需要改
- **踩坑**：用 `mv` 而非 `git mv` 后，`git add -A <新路径>` 只暂存了 A、删除仍是未暂存的 ` D`，
  直接提交会让旧文件残留。修法：`git rm -r --cached db deploy doc` 精确暂存删除；
  用 `git add -u` 会把未完成的 agent 代码一起带进去。提交后 rename 检测为 65 个 R
