# 2026-09-14

## 日志按日期目录归档（commit 29faf35）

用户嫌 logs 下零散（4 种日志 × 7 天 = 28 个 .gz 散在根目录），要求按日期建父目录。

**改动**：`logback-spring.xml` 4 个 appender 的 fileNamePattern
```
旧：${LOG_HOME}/${APP_NAME}.%d{yyyy-MM-dd}.%i.log.gz
新：${LOG_HOME}/%d{yyyy-MM-dd}/${APP_NAME}.%i.log.gz   ← 日期挪到目录位
```
- `<file>` 保持不变（Logback 的 file 不支持 %d，活动日志固定在根目录，滚动时按 pattern 归档）
- **必须重启应用**：配置在启动时加载，运行中改文件不会热生效，不重启的话当天 0 点滚动仍走旧 pattern
- 存量归档用 shell 循环迁进日期目录，并统一去掉文件名里冗余的日期
  （目录已含日期，文件名再带一遍是冗余）

最终结构：
```
logs/
├── 2026-09-07/ ... 2026-09-13/   每天 4 个：dong / -debug / -warn / -error 的 .0.log.gz
├── dong.log  dong-debug.log  dong-warn.log  dong-error.log   ← 当天活动日志
```
