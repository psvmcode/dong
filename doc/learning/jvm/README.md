## 容易混淆的两组概念

| 概念 | 是什么 |
|---|---|
| **JMM**（内存模型） | 多线程**读写规范**，规定可见性 |
| **运行时数据区**（堆/栈/方法区） | 内存**怎么分区**，放什么东西 |

名字里都有「内存」，但完全是两回事，别混。
