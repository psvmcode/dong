# 知识点学习

> 本目录记录**通用技术知识点**的整理与理解，不绑定某个具体模块。
> 写法追求「讲人话」：先说清楚解决什么问题，再说机制，最后给判断标准。

---

## 与另外两个目录的区别

| 目录 | 内容 | 回答的问题 |
|---|---|---|
| [`../scenario/`](../scenario/README.md) | 项目模块全景 | 这个模块整体长什么样 |
| [`../topic/`](../topic/README.md) | 专题深挖 | 这一点为什么这么设计 |
| `doc/learning/`（本目录） | **通用知识点** | 这个知识点本身是怎么回事 |

前两个围绕本项目，本目录脱离具体项目，是可以长期积累、随时回看的知识库。
